## M-9J2e 候補生成の強化

### 実装
`tools/gpu_hints.c` で各 MB に 4 候補を生成:
- (a) 1/2 解像度 ME 最良 MV ×2
- (b) ゼロ MV
- (c) 左 MB の低解像度 MV
- (d) 上 MB の低解像度 MV

各候補を full-res ±8 整数リファインし、**SAD** 最小を採用。
SATD は未実装（aeg の SATD バッチは full-res 参照プレーンの
登録が必要で、今回の帯分割と両立しない）。

### vtestL / CRF27 / limit:6

| 候補 | 出力 |
|---|---:|
| 1 候補（旧） | 172,012 B |
| **4 候補（新）** | **170,800 B** |
| base | 158,327 B |

- +8.6% → **+7.9%**。改善はわずかで、ゲート未達。

### cockL / CRF27

| limit | 出力 |
|---:|---:|
| 2 | 133,077 |
| 4 | 111,087 |
| 6 | 99,893 |

- base 99,967。limit:6 で同等。
- 4 候補でも旧値（99,823）とほぼ同じ。

### 生成時間
- 640p 240f: **2.48 s**（旧 2.25 s）。4 候補でも +0.2 s。

### 判定

| 項目 | 結果 |
|---|---|
| vtestL +8.6% の解消 | **NO（+7.9%）** |
| 候補不足 | 4 候補でも不足 |
| コスト関数 | SAD のみ。SATD 未導入 |
| +0.5% 以内の最小 N | **未確定** |
| E2E | 時間は勝ち、品質負け |
| 案C 実証 | **未達** |

残差の主因:
- 1/2 解像度 ME の MV 精度（候補 4 本を足しても改善小）。
- SATD/qpel 候補なし。
- x264 の qpel は局所改善のみで、初期整数 MV の差を埋めない。

### 次
- SATD バッチ（8x8 Hadamard）を aeg に追加し、候補選択を SATD 化。
- 1/2 解像度で上位 2 候補を返す lowres 探索。
- 初期 MV を x264 の `pmv` / 前フレーム MV に寄せる。
